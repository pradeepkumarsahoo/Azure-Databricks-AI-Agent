PolicyPilot Architecture

Governed agentic Q&A over SEC 10-K filings — Azure Databricks + LangGraph + hybrid retrieval

PolicyPilot ingests SEC 10-K filings from EDGAR, chunks and embeds them into a hybrid vector store, then routes each user question through a LangGraph agent that expands the query, retrieves and reranks the most relevant passages, and generates a cited answer — refusing to respond if no grounded citation can be found. The same codebase runs locally on a laptop via Chroma and Groq, and in production on Azure Databricks with Vector Search, Unity Catalog, and a governed AI Gateway in front of the LLM.
